### Векторные операции

Сложение, умножение на скаляр и поэлементное умножение записываются обычными
операторами `+` и `*`. NumPy применяет их сразу ко всему массиву:

```python
def vector_add(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Сложить два вектора поэлементно (без циклов, векторизованно).

    Args:
        a: Первый вектор.
        b: Второй вектор той же длины.

    Returns:
        Результат поэлементного сложения.
    """
    return a + b
```

Это и есть векторизация. Цикл `for` не нужен, операция выполняется в
скомпилированном коде и работает в разы быстрее.

### Матричные операции

```python
def solve_linear_system(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Решить систему линейных уравнений A @ x = b."""
    return np.linalg.solve(a, b)
```

Ещё реализованы `matrix_multiply` (`a @ b`), `matrix_determinant`
(`np.linalg.det`) и `matrix_inverse` (`np.linalg.inv`).

### Статистический анализ

```python
def statistical_analysis(data: np.ndarray) -> dict[str, float]:
    """Посчитать основные статистические характеристики набора данных."""
    return {
        "mean": np.mean(data),
        "median": np.median(data),
        "std": np.std(data),
        "min": np.min(data),
        "max": np.max(data),
        "p25": np.percentile(data, 25),
        "p75": np.percentile(data, 75),
    }
```

### Мелочи, которые стоили времени

!!! note "Бэкенд Matplotlib"
    При запуске тестов графического окна нет, поэтому в начале модуля
    включается бэкенд `Agg` (`matplotlib.use("Agg")`) и графики рисуются
    прямо в файл. Без этого тесты визуализации зависают в окружении без GUI.

!!! warning "`plt.close()` после каждого графика"
    Matplotlib рисует всё в одну «текущую» фигуру. Если её не закрывать,
    второй график ляжет поверх первого. Сохранение и закрытие вынесены во
    вспомогательную функцию `_save_plot`.

!!! note "`np.std` считает смещённое отклонение"
    По умолчанию делит на `n`, а не на `n - 1`. Для несмещённой оценки нужен
    `np.std(data, ddof=1)`.

!!! danger "Деление на ноль в нормализации"
    Если все элементы массива равны, то `max - min = 0`, и формула min-max
    даёт деление на ноль. В учебных данных такого нет, но в боевом коде этот
    случай надо обрабатывать отдельно.

### Про длину строк

`black` по умолчанию форматирует под 88 символов, а `flake8` без настроек

руками, чтобы `flake8` проходил без дополнительных аргументов.
