## Как устроены отчёты

Код во всех работах писался с оглядкой на DAST / DATS: тесты, аннотации типов
по PEP 484, докстринги по PEP 257, стиль по PEP 8 с проверкой через `flake8`.

В каждом отчёте есть раздел с разбором мест, где я ошибся или где результат
получился неожиданным. Мне кажется, из него понятнее, чем из голых цифр.
