    ЛР 2. Основы NumPy: массивы и векторные операции¶

    Цель работы¶

    Освоить библиотеку NumPy: создание массивов, векторные и матричные операции, статистический анализ данных и визуализацию через Matplotlib и Seaborn.

    Задание¶

    Реализовать 17 функций так, чтобы проходили тесты. Код должен содержать аннотации типов (PEP 484), докстринги (PEP 257) и соответствовать PEP 8.

    Структура проекта:

    numpy_lab/
├── main.py
├── test.py
├── data/students_scores.csv
└── plots/

    Код работы: github.com/mptin/python-labs, каталог lab_02.

    Реализация¶

    Создание и обработка массивов¶

    Функция Что делает Инструмент
    create_vector массив [0..9] np.arange(10)
    create_matrix матрица 5×5 случайных чисел [0, 1) np.random.rand(5, 5)
    reshape_vector форма (10,) в (2, 5) vec.reshape(2, 5)
    transpose_matrix транспонирование mat.T

    Векторные операции¶

    Сложение, умножение на скаляр и поэлементное умножение записываются обычными операторами + и *. NumPy применяет их сразу ко всему массиву:

    def vector_add(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Сложить два вектора поэлементно (без циклов, векторизованно).

    Args:
        a: Первый вектор.
        b: Второй вектор той же длины.

    Returns:
        Результат поэлементного сложения.
    """
    return a + b

    Это и есть векторизация. Цикл for не нужен, операция выполняется в скомпилированном коде и работает в разы быстрее.

    Матричные операции¶

    def solve_linear_system(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Решить систему линейных уравнений A @ x = b."""
    return np.linalg.solve(a, b)

    Ещё реализованы matrix_multiply (a @ b), matrix_determinant (np.linalg.det) и matrix_inverse (np.linalg.inv).

    Статистический анализ¶

    def statistical_analysis(data: np.ndarray) -> dict[str, float]:
    """Посчитать основные статистические характеристики набора данных."""
    return {
        "mean": np.mean(data),
        "median": np.median(data),
        "std": np.std(data),
        "min": np.min(data),
        "max": np.max(data),
        "p25": np.percentile(data, 25),
        "p75": np.percentile(data, 75),
    }

    Визуализация¶

    Три функции строят гистограмму распределения оценок, тепловую карту корреляции предметов (np.corrcoef) и график «студент, балл». Каждая сохраняет результат в папку plots/.

    Мелочи, которые стоили времени¶

    Бэкенд Matplotlib

    При запуске тестов графического окна нет, поэтому в начале модуля включается бэкенд Agg (matplotlib.use("Agg")) и графики рисуются прямо в файл. Без этого тесты визуализации зависают в окружении без GUI.

    plt.close() после каждого графика

    Matplotlib рисует всё в одну «текущую» фигуру. Если её не закрывать, второй график ляжет поверх первого. Сохранение и закрытие вынесены во вспомогательную функцию _save_plot.

    np.std считает смещённое отклонение

    По умолчанию делит на n, а не на n - 1. Для несмещённой оценки нужен np.std(data, ddof=1).

    Деление на ноль в нормализации

    Если все элементы массива равны, то max - min = 0, и формула min-max даёт деление на ноль. В учебных данных такого нет, но в боевом коде этот случай надо обрабатывать отдельно.

    Про длину строк¶

    black по умолчанию форматирует под 88 символов, а flake8 без настроек проверяет по 79. Если прогнать black и сразу flake8, получишь ошибки E501 на ровном месте. В этой работе я оставил лимит 79 и поправил строки руками, чтобы flake8 проходил без дополнительных аргументов.

    Выводы¶

    Главное, что даёт NumPy, это возможность описать операцию над целым массивом одной строкой. Вместо явных циклов пишутся операторы и функции, работающие сразу над всеми элементами, и код от этого становится короче, читаемее и заметно быстрее.

    Связка NumPy, pandas и Matplotlib закрывает полный цикл от загрузки данных до картинки.

    Требования DAST/DATS выполнены: аннотации типов, докстринги, соответствие PEP 8 проверено flake8, код покрыт 17 тестами.
